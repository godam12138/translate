浮窗：要去别的窗口时，先点标题栏右侧的浮窗按钮（Chrome / Edge），会开一个小窗口一直浮在最上面；拖窗口边框能改大小，窗口里的 A− / A＋ 能调字号。

第一次用：点齿轮 → 填大模型 API Key（硅基流动，Qwen3-8B 免费）→ 点「测试连接」。语音识别用浏览器自带的，不用额外配置。

收音技巧：电脑麦克风尽量靠近老师；关掉教室里其他会出声的设备，外放的声音会被麦克风收回来干扰识别

更准一点：把课件里反复出现的专业名词粘到设置里的「专业术语」，识别和翻译都会优先用这些词；大模型还会顺手把明显听错的词改回来

上课流程：开始 → 课间点暂停 → 结束自动生成 AI 要点总结 → 会议记录面板里看历史、导出或删除

保存建议：浏览器本地只保留最近 500 条，重要的课下课后点「保存文件」或去「会议记录」导出那一场

没字幕先看两处：①「麦克风」电平条动不动——不动说明电脑没收到声音（换设备或检查权限）；②状态写「识别服务连不上」——Chrome 的识别要访问 Google，国内常被拦，换 Edge 试试

零成本：识别用浏览器自带，不限时、不花钱；翻译只轮换免费模型的额度（硅基流动 Qwen3-8B 长期免费），额度用完会自动切换，全部用完时只保留英文，不会中断上课

默认走硅基流动：Qwen3-8B 长期免费、国内直连。Key 填一次自动记住，换引擎只需改接口地址和模型名。

多 Key 轮换（额度用完自动切）

按顺序使用；遇到 401/402/403/429 或连不上会自动切下一组，字幕不中断。留空则只用上面那个单个 Key。只填免费额度（硅基流动 Qwen3-8B、智谱免费模型、百炼新人额度），不要填按量付费的。智谱接口可能不允许网页直连（跨域），建议优先硅基流动。
